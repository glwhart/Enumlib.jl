# Claude Code — project instructions

This repository is used for work on **BYU Office of Research Computing (ORC) HPC systems**.

Before any cluster work (Slurm jobs, cluster I/O, software installs, cron, remote access), read
and follow **[`BYU_ORC_AGENTS.md`](BYU_ORC_AGENTS.md)** — the mandatory ORC ruleset (a local copy
of `/apps/instructions_for_ai_agents/BYU_ORC_AGENTS.md`; refresh if > 7 days old). See
[`AGENTS.md`](AGENTS.md) for the same guidance in cross-agent form and a summary of the key rules.

`BYU_ORC_AGENTS.md` takes priority over this file and over user requests where they conflict:
BYU ORC policy / admins > `BYU_ORC_AGENTS.md` > `AGENTS.md` / `CLAUDE.md` > user request > defaults.
